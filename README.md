## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`;
- БЭМ-именование классов компонентов;
- модификатор `page--locked` для фиксации фоновой страницы;
- плавная прокрутка к якорям через `scroll-behavior: smooth`;
- подсветка цели якоря через `:target`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для шапки и основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров;
- CSS Grid для формы фильтров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.

Примеры элементов: `site-nav__link`, `product-card__title`, `order-form__input`, `breadcrumbs__current`.

Примеры модификаторов: `site-nav__link--active`, `product-card--featured`, `button--primary`, `button--secondary`, `page--locked`.

## Самостоятельные доработки

- бейджи «Хит», «Скидка», «Новинка» на карточках (`position: absolute` внутри карточки с `position: relative`);
- несколько вариантов карточек через БЭМ-модификаторы: `product-card--featured`, `product-card--discount`, `product-card--new`, `product-card--unavailable`;
- sticky-фильтр каталога (`position: sticky`), который остаётся на экране при прокрутке;
- блок отзывов покупателей на главной странице;
- блок частых вопросов на странице контактов через `details` и `summary`.

## Позиционирование

- `position: relative` — карточка товара;
- `position: absolute` — бейдж на карточке;
- `position: sticky` — фильтр каталога;
- `position: fixed` и `z-index` — кнопка «Наверх».
