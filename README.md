# Учебный frontend-проект «CoreMirea» (Контрольная работа №3)

Тема: «Адаптивная вёрстка, доступность и интерактивный пользовательский интерфейс многостраничного сайта магазина комплектующих и сборки ПК».

## Описание

Проект **«CoreMirea»** представляет собой адаптивный многостраничный сайт специализированного интернет-магазина компьютерных комплектующих и лаборатории кастомной сборки ПК (видеокарты GeForce RTX / Radeon RX, процессоры AMD Ryzen и Intel Core, материнские платы AM5 / LGA 1700, оперативная память DDR5, NVMe-накопители, СЖО, блоки питания и корпуса).

Архитектура разделена по слоям **без использования CSS-фреймворков (без Bootstrap)**:
- **HTML5** — семантическая многостраничная структура (`header`, `nav`, `main`, `section`, `footer`, `dialog`, `details`/`summary`, `picture`, `srcset`, `sizes`);
- **CSS3 (`css/style.css` + `css/responsive.css`)** — собственная дизайн-система на БЭМ и CSS-переменных, тёмная и светлая темы с плавным переключением, подход **Mobile First** (`@media (min-width: ...)`), Flexbox и CSS Grid;
- **JavaScript (`js/store.js`, `js/main.js`, `js/product.js`)** — бизнес-логика, каталог с актуальными ценами и характеристиками, расчёт совместимости сокетов и энергопотребления, синхронизация с `localStorage`;
- **React 18 (`js/react-ui.js`)** — библиотека пользовательского интерфейса для реактивных компонентов (шапка действий с живым счётчиком избранного, чат-консультант со сборщиком ПК, живой поиск и фильтрация каталога, избранное, личный кабинет и интерактивный конфигуратор сборки ПК).

## Ключевые возможности интерфейса

- **Основная навигация из 4 разделов:** `Главная`, `Каталог`, `О магазине`, `Контакты`; дополнительные разделы (`Избранное`, `Личный кабинет`, `Конфигуратор ПК`, `Карточка товара`, `Подборка 2K`) вынесены на отдельные страницы.
- **Переключатель тёмной и светлой темы** в шапке с сохранением выбора в `localStorage` и плавными CSS-переходами.
- **Онлайн чат-консультант со сборщиком ПК (слева внизу)** на React с быстрыми вопросами по сокетам AM5 / LGA 1700, видеокартам, расчёту блока питания и промокодам.
- **Стилизованная кнопка «Наверх» (справа внизу)** с плавной прокруткой без использования символов стрелок.
- **Трёхколоночный подвал:** слева бренд с графическим SVG-знаком, слоган и копирайт `© 2026`; по центру навигация с иконками (без дублирования контактов); справа контактные данные с иконками.
- **Живой поиск, фильтрация по сокету/цене/наличию и сортировка** в каталоге на React.
- **Избранное** с живым счётчиком в шапке и расчётом общей стоимости отложенного железа.
- **Личный кабинет** с историей заказов и сборок, редактируемым профилем, бонусным счётом `CoreClub` и копированием промокодов (`MIREA10`, `BUILD1500`).
- **Интерактивный конфигуратор сборки ПК** с автоматической проверкой совместимости сокетов процессора и материнской платы (`Socket AM5` / `Socket LGA 1700`) и оценкой энергопотребления в ваттах.
- **Responsive Images и Mobile First:** элемент `<picture>`, атрибуты `srcset`, `sizes`, `loading="lazy"`, адаптивные таблицы в `.table-wrapper`, проверенные ширины `360px`, `430px`, `768px`, `1024px`, `1440px`.
