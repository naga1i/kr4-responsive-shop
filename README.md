# Интернет-магазин компьютерных комплектующих «CoreMirea»

Многостраничный адаптивный сайт интернет-магазина компьютерных комплектующих (видеокарты NVIDIA GeForce RTX и AMD Radeon RX, процессоры AMD Ryzen и Intel Core, материнские платы AM5 / LGA 1700, оперативная память DDR5, NVMe SSD, системы охлаждения, блоки питания и корпуса).

## Технологический стек

Проект выполнен **без использования CSS-фреймворков (без Bootstrap)**:
- **HTML5** — семантическая разметка (`header`, `nav`, `main`, `section`, `footer`, `dialog`, `details`/`summary`, `picture`, `srcset`, `sizes`);
- **CSS3 (`css/style.css` + `css/responsive.css`)** — собственная дизайн-система на БЭМ и CSS-переменных, тёмная и светлая темы, подход **Mobile First** (`@media (min-width: ...)`), Flexbox и CSS Grid;
- **JavaScript (`js/store.js`, `js/main.js`, `js/product.js`)** — бизнес-логика, каталог товаров, хранение состояния в `localStorage`;
- **React 18 (`js/react-ui.js`)** — пользовательский интерфейс (панель пользователя в шапке, чат-консультант, живой поиск и фильтрация каталога, личный кабинет и форма заказа).

## Структура проекта

```text
kr4-responsive-shop/
├── index.html          # Главная (Hero, преимущества, популярные товары, отзывы)
├── catalog.html        # Каталог 12 комплектующих (React: поиск, фильтры, сортировка)
├── about.html          # О магазине (история, показатели, принципы работы)
├── contacts.html       # Контакты, режим работы, интерактивная Яндекс Карта и FAQ
├── order.html          # Оформление заказа (React) и таблица условий доставки
├── product.html        # Карточка товара + таблицы характеристик и сравнения видеокарт
├── account.html        # Личный кабинет: история заказов, профиль, бонусы (React)
├── category.html       # Подборка популярных комплектующих
├── css/
│   ├── style.css       # Тёмная/светлая тема, БЭМ-компоненты, карточки, формы, чат, подвал
│   └── responsive.css  # Адаптивная вёрстка Mobile First (360px — 1440px)
├── js/
│   ├── vendor/         # Локальная сборка React 18 и ReactDOM 18
│   ├── store.js        # Бизнес-логика, база комплектующих и localStorage-хранилище
│   ├── main.js         # Кнопка «Наверх» и модальное окно <dialog>
│   ├── product.js      # Заполнение карточки товара по ?id=1..12
│   └── react-ui.js     # Интерфейс пользователя на React 18
├── images/             # Фотографии комплектующих и адаптивные версии 320w–960w
├── README.md
└── .gitignore
```

## Реализованные возможности

- **Навигация в шапке из 4 разделов:** `Главная`, `Каталог`, `О магазине`, `Контакты`; дополнительные разделы (`Личный кабинет`, `Оформление заказа`, `Карточка товара`) вынесены на отдельные страницы.
- **Переключатель тёмной и светлой темы** с сохранением выбора в `localStorage`.
- **Чат-консультант (слева внизу)** на React с быстрыми вопросами и ответами.
- **Стилизованная кнопка «Наверх» (справа внизу)** без стрелок.
- **Трёхколоночный подвал:** слева логотип с графическим SVG-знаком, слоган и `© 2026`; по центру навигация с иконками без контактов; справа контактные данные с иконками.
- **Каталог с живым поиском, фильтрацией и сортировкой**, **Личный кабинет** и **Оформление заказа** на React 18.
- **Адаптивная вёрстка Mobile First** и **Responsive Images** (`picture`, `srcset`, `sizes`, `loading="lazy"`), проверено на `360px`, `430px`, `768px`, `1024px`, `1440px`.
